PUT YOUR PICTURES HERE
======================
Every page looks for these file names. Until a file exists, a dashed
placeholder box is shown in its place, so you can add them one by one.

  logo-icon.png      PyPath logo (sidebar, top bar, login, browser tab)
  avatar.png         student profile photo (top bar, drawer, profile page)
  mascot-hands.png   sidebar mascot
  mascot-wave.png    home page welcome card
  mascot-cheer.png   login page + quiz passed
  mascot-sad.png     "nothing found" messages + quiz failed
  mascot-star.png    home "Keep going" card + points & rewards
  mascot-wink.png    (spare, same as the admin side)

Transparent PNGs look best. If you use the admin pictures, copy them
from  PyPath Admin/assets/img/  into this folder.
